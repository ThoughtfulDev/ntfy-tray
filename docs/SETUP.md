# Set up ntfy-tray

[← Back to the README](../README.md)

## Install

Download the DMG from the latest GitHub Release, open it, and move `ntfy-tray.app` to Applications.

Releases are intentionally ad-hoc signed. If macOS asks for confirmation when you first open the app, use the standard **Open Anyway** or **Open** action in macOS privacy settings.

## First launch

The welcome flow guides you through the initial setup:

1. Choose the default ntfy server or enter your own HTTPS server.
2. Optionally add a bearer token.
3. Add one or more topics.
4. Allow notifications when macOS asks.

The app then stays in the menu bar. Open the Inbox from its menu whenever you want to catch up.

## Make it yours

Topics can have their own icons, and quiet hours or Do Not Disturb can pause alerts while keeping messages available in the Inbox.

All server URLs must use HTTPS.
